skfilter

A Windows-only allowlist firewall with a password-gated local dashboard. Default-deny outbound; only domains you've explicitly added can be reached.

Browser extension

On managed installs, skfilter.exe -install writes Chrome / Edge ExtensionInstallForcelist policy keys that point at update.xml on this site. The extension is then force-installed and cannot be disabled by the user.

For a manual install: chrome://extensions → toggle Developer mode → Load unpacked → pick the extension/ folder from the repo. Or drop skfilter.crx onto the Extensions tab.

What is this?

skfilter is a self-discipline tool. It runs as a Windows service, sets the Windows firewall to default-deny outbound, and lets you add domains to an allowlist through a local dashboard at http://localhost:8764. Removing a domain has a 10-second hold to discourage in-the-moment overrides. A reconciler loop reverts out-of-band netsh changes within a few seconds.

The browser extension is UX, not enforcement. When you navigate to a non-allowlisted site the extension redirects to the dashboard's "Request access" page so you can decide whether to add the domain. The firewall does the actual blocking regardless of which browser you use.
